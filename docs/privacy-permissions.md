# PromptCrate 权限与隐私说明

## 权限说明

PromptCrate 使用 Manifest V3，并只申请 MVP 必需权限：

| 权限 | 用途 |
|---|---|
| `activeTab` | 仅在用户主动触发快捷键或点击扩展时，允许当前标签页被临时访问。 |
| `scripting` | 将页面内菜单和插入逻辑注入到当前活动页面。 |
| `storage` | 使用 `chrome.storage.local` 保存本地模板、收藏状态和最近使用时间。 |

当前版本不申请 `<all_urls>`、`tabs`、`history`、`clipboardRead`、`clipboardWrite`、远程主机权限或后台网络权限。

## 隐私说明

- 模板数据默认只保存在本机浏览器的 `chrome.storage.local`。
- 不需要账号，不注册，不登录。
- 不上传模板、变量值、网页内容或使用记录。
- 不默认读取网页正文。
- 不调用远程 AI 服务。
- 不做云同步、团队空间或模板市场。

## 数据边界

PromptCrate 只在用户主动打开菜单并选择模板后，将渲染后的文本插入当前聚焦输入区域。变量填写内容默认只用于本次渲染，不单独持久化。只有用户在 Options 主动开启“记住变量值”后，普通变量值才按模板和变量名保存在本机的 `chrome.storage.local`。关闭会清空缓存，也可单独清除已记住的值；模板导入导出不包含这些值。模板本身、标签、收藏和最近使用时间会保存在本地，供菜单排序和 Options 管理使用。

内置变量只在用户选择明确引用它们的模板时读取对应信息：`@url` 和 `@title` 读取当前 frame 的 URL 和标题，`@selection` 只读取打开菜单前保存的输入框或可编辑区域选区。没有选区时为空，不扫描页面正文。日期和时间取自本机时钟；这些内置值不写入变量记忆。

界面语言偏好也保存在本机。界面支持英文与简体中文，默认跟随浏览器语言；手动切换只改变界面。默认模板仅在新初始化模板库时按所选语言生成，已有模板内容不会被翻译或覆盖。

菜单使用 closed Shadow DOM，引用只保存在内容脚本的隔离环境中。普通网页通过 `host.shadowRoot` 不能读取菜单里的模板库或变量表单；网页创建的同名宿主节点也不会被复用。打开菜单通过扩展快捷键或工具栏图标触发，网页派发的 `promptcrate:open-menu` 事件不再是入口。菜单拒绝合成的点击、键盘和提交事件。

这项防护针对直接读取菜单 DOM、伪造控件事件和网页控制菜单打开的路径；不承诺屏蔽 document 捕获阶段的事件观察。用户确认插入网页的文本仍由网页正常读取。

## 发布前复核

每次发布前检查：

- `manifest.json` 权限是否仍是最小集合。
- `src/content/content-entry.ts` 是否仍不读取页面正文。
- `src/shared/storage.ts` 是否仍只使用本地存储。
- 打包产物中是否没有新增远程请求代码。
- 网页主世界读取菜单宿主的 `shadowRoot` 是否返回 `null`，模板和变量是否没有进入宿主节点的普通 DOM。
- 伪造 `promptcrate:open-menu`、点击、键盘和提交事件是否不能打开或操作菜单。
- 工具栏点击与快捷键是否都通过扩展入口打开正确标签页和 frame 的菜单。
